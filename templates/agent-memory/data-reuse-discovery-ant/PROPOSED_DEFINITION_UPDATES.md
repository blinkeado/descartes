# Proposed definition updates

> The executor does not edit its own definition. It proposes here; the coordinator validates the YAML
> and the logic and applies it, and the change takes effect at the next session start.
> Proposals that weaken a TOP RULE, grant scheduling/tool permissions, or permit believing on first
> look are not applicable: they are routed to the human.
